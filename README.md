# Шахматка — виджет выбора квартир (ЖК «Крылья»)

Встраиваемый виджет «шахматка» для застройщика: генплан с кликабельными подъездами →
фильтры (дом, комнаты, цена/площадь/этаж) → карточки планировок и таблица **этажи × стояки**.
Клик по квартире открывает панель с реальной планировкой, метражом, ценой и кнопкой заявки.

Самописный аналог Domoplaner — без подписки, на статичных данных из фида застройщика.

## Текущая сборка — ЖК «Крылья» (Тверь)
- Данные из реального фида застройщика: **97 квартир, подъезды 7–10** (секция 1 = 7,8; секция 2 = 9,10).
- Цена — столбец «Стоимость кв-ры, ипотека / 100% оплата».
- Реальные техпланы застройщика (`plans/*.webp`); 3 редкие квартиры без чертежа показывают схему с пометкой.
- Статусов в фиде нет → все квартиры свободны.
- Генплан — обработанное аэрофото комплекса (`genplan.jpg`) с пинами подъездов.

## Файлы
| Файл | Назначение |
|------|------------|
| `shahmatka.js`  | Виджет, vanilla JS, без зависимостей |
| `shahmatka.css` | Стили (переопределяются через CSS-переменные `--shm-*`) |
| `data.json`     | Данные о квартирах (генерируются скриптом) |
| `generate_data.py` | Сборка `data.json` из фида (`.xlsx`, без openpyxl) |
| `plans/`        | Реальные планировки `*.webp` |
| `genplan.jpg`   | Подложка генплана |
| `index.html`    | Демо-страница |

## Перегенерировать данные из нового фида
```powershell
cd shahmatka-widget
python generate_data.py          # читает фид из ..\wiki\материалы крылья\ЖК Крылья фид ....xlsx
```
Путь к фиду можно переопределить переменной окружения `KRYLIA_FEED`.
Колонки фида: A=№, B=подъезд, C=этаж, D=комнаты, E=площадь, F=₽/м², **G=цена**.
Привязка планировок и координаты пинов подъездов — словари `PLANS` и `PIN` в скрипте.

## Как посмотреть
Виджет читает `data.json` через `fetch` — нужен локальный сервер:
```powershell
python -m http.server 8080   # http://localhost:8080
```

## Интеграция на сайт
```html
<link rel="stylesheet" href="shahmatka.css">
<div id="shahmatka"></div>
<script src="shahmatka.js"></script>
<script>
  Shahmatka.init({
    container: '#shahmatka',
    dataUrl: 'data.json',
    onLead: function (flat) {
      // flat — объект квартиры; здесь: форма заявки / amoCRM / Метрика-цель
    }
  });
</script>
```

## Формат `data.json`
```jsonc
{
  "project": "ЖК «Крылья»",
  "currency": "₽",
  "genplan": {
    "image": "genplan.jpg",
    "buildings": [
      { "id": "p7", "name": "Подъезд 7", "tag": "секция 1",
        "floors_label": "10 этажей · 19 кв.", "xPct": 29, "yPct": 40 }
    ]
  },
  "statuses": {
    "free":     { "label": "Свободна", "color": "#3f9d58" },
    "reserved": { "label": "Бронь",    "color": "#e0a312" },
    "sold":     { "label": "Продана",  "color": "#c0392b" }
  },
  "flats": [
    {
      "id": "kr251", "number": "251",
      "building": "p7",          // = подъезд (связь с genplan.buildings.id)
      "floor": 1, "riser": 1,    // строка/столбец шахматки
      "rooms": 1, "area": 44.33, "price": 5452590,
      "status": "free", "finishing": "под ключ",
      "plan": "plans/p_44_3_p7.webp"   // реальная планировка (опц.)
    }
  ]
}
```
Этажи и стояки виджет выводит сам из массива `flats`.
