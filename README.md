# Шахматка — виджет выбора квартир

Универсальный встраиваемый виджет «шахматка» для застройщиков: таблица **этажи × стояки**,
ячейки покрашены по статусу (свободна / бронь / продана), клик по квартире открывает карточку
с планировкой, метражом, ценой и кнопкой заявки.

Аналог того, что у Иллидиума делает Domoplaner — но самописный, без подписки, на статичных данных.

## Файлы
| Файл | Назначение |
|------|------------|
| `shahmatka.js`  | Сам виджет, vanilla JS, без зависимостей |
| `shahmatka.css` | Стили (можно переопределять через CSS-переменные `--shm-*`) |
| `data.json`     | Данные о квартирах — **это редактирует застройщик** |
| `index.html`    | Демо-страница |

## Как посмотреть
Виджет читает `data.json` через `fetch`, поэтому нужен локальный сервер (просто открыть файл с `file://` не даст загрузить JSON):

```powershell
cd shahmatka-widget
python -m http.server 8080
# открыть http://localhost:8080
```

## Интеграция на чужой сайт
```html
<link rel="stylesheet" href="shahmatka.css">
<div id="shahmatka"></div>
<script src="shahmatka.js"></script>
<script>
  Shahmatka.init({
    container: '#shahmatka',
    dataUrl: 'data.json',
    onLead: function (flat) {
      // flat — объект квартиры из data.json
      // здесь: открыть форму заявки / отправить в CRM / Метрика-цель
    }
  });
</script>
```

## Формат данных (`data.json`)
```jsonc
{
  "project": "ЖК «Атмосфера»",   // заголовок
  "building": "Корпус 1",         // подзаголовок
  "currency": "₽",
  "statuses": {                   // статусы и их цвета (можно менять/добавлять)
    "free":     { "label": "Свободна", "color": "#3f9d58" },
    "reserved": { "label": "Бронь",    "color": "#e0a312" },
    "sold":     { "label": "Продана",  "color": "#c0392b" }
  },
  "flats": [
    {
      "id": "316043",       // уникальный id
      "number": "84",       // номер квартиры (на ячейке)
      "floor": 16,          // этаж — строка таблицы
      "riser": 3,           // стояк — столбец таблицы
      "rooms": 2,           // 0 = студия
      "area": 54.3,         // м²
      "price": 8200000,     // ₽
      "status": "free",     // ключ из statuses
      "finishing": "черновая"
    }
  ]
}
```
Этажи и стояки виджет выводит сам из массива `flats` — отдельно их перечислять не нужно.

## Что уже есть
- **Генплан** (вид сверху) с кликабельными корпусами; цвет корпуса = доступность (зелёный/жёлтый/красный), бейдж «N свободно»
- Клик по корпусу → его шахматка, кнопка «← К генплану»
- Таблица этажи × стояки, авторазметка из данных
- Цветовые статусы + легенда со счётчиками
- Фильтр по комнатности
- Карточка квартиры (выезжает справа) с ценой за м² и кнопкой заявки
- Колбэк `onLead` — точка подключения формы / CRM
- Адаптив (горизонтальный скролл таблицы на мобиле)

## Генплан (`data.json` → `genplan`)
Корпуса заданы прямоугольниками в координатах `viewBox`. Сейчас подложка рисуется
схемой (парк/дороги/пруд) прямо в SVG — это самодостаточно и корпуса кликаются точно.
```jsonc
"genplan": {
  "viewBox": "0 0 960 600",
  "buildings": [
    { "id": "k1", "name": "Корпус 1", "floors_label": "9 этажей",
      "x": 150, "y": 360, "w": 190, "h": 120 }   // прямоугольник корпуса
  ]
}
```
Свободные и статусы корпус считает сам из `flats` (по полю `building`).

### Подменить схему реальным рендером
Механизм «кликабельных зон поверх картинки» тот же. Чтобы поставить фото-рендер ЖК:
1. Положить картинку (напр. `genplan.jpg`) и вставить её первым элементом SVG-сцены:
   `<image href="genplan.jpg" width="960" height="600"/>` вместо рисованной подложки
   (функция сцены — в `shahmatka.js`, метод `showGenplan`).
2. Подобрать `x/y/w/h` каждого корпуса под пиксели картинки (в том же `viewBox`).
   Прямоугольник можно заменить на `points` многоугольника, если корпус не прямой.

## Перегенерировать данные
`data.json` собран скриптом `generate_data.py` (3 корпуса, 78 квартир, фиксированный seed).
Правишь конфиг корпусов в скрипте → `python generate_data.py`.
